# Iterable

Generate iterable values.

## iterator

Generate `Iterator` of values generated by `arb`.

**Signatures:**

- `fc.iterator(arb)`
- `fc.iterator(arb, {minLength?, maxLength?, noDefaultInfinity?, size?, noHistory?})`

**with:**

- `arb` — _arbitrary instance responsible to generate values_
- `minLength?` — default: `0` — _minimal number of items the generated iterators will yield before completing (included). `Number.POSITIVE_INFINITY` is accepted: it forces every generated iterator to be a never-ending one_
- `maxLength?` — default: `Number.POSITIVE_INFINITY` (`Number.MAX_SAFE_INTEGER` when `noDefaultInfinity` is `true`) — _maximal number of items the generated iterators will yield before completing (included). `Number.POSITIVE_INFINITY` means never-ending iterators may be generated, any finite value makes every generated iterator finite_
- `noDefaultInfinity?` — default: `false` — _move the default `maxLength` from `Number.POSITIVE_INFINITY` to `Number.MAX_SAFE_INTEGER` so that only finite iterators get generated. An explicit `maxLength: Number.POSITIVE_INFINITY` still wins over it_
- `size?` — default: `undefined` [more](/docs/configuration/larger-entries-by-default/#size-explained) — _how large should the generated values be? It caps the number of items the generated finite iterators will yield the same way it caps the length of arrays, `maxLength` staying the hard upper bound. It has no impact on never-ending iterators_
- `noHistory?` — default: `false` — Omit generated values from the string representation. Recommended for very large tests due to the history's unbounded memory use.

**Usages:**

```js
fc.iterator(fc.nat(9));
// Note: From time to time, generated iterators are never-ending ones
// Examples of generated values:
// • Iterator.from([/*1 others…*/])
// • Iterator.from([/*6 others…*/])
// • Iterator.from([/*10 others…*/])
// • Iterator.from([/*4 others…*/])
// • Iterator.from([/*5 others…*/])
// • …

fc.iterator(fc.nat(9), { minLength: 2, maxLength: 5 });
// Note: Only finite iterators yielding between 2 and 5 items
// Examples of generated values: Iterator.from([/*2 others…*/]), Iterator.from([/*3 others…*/])…

fc.iterator(fc.nat(9), { noDefaultInfinity: true });
// Note: Only finite iterators
// Examples of generated values:
// • Iterator.from([/*2 others…*/])
// • Iterator.from([/*3 others…*/])
// • Iterator.from([/*6 others…*/])
// • Iterator.from([/*10 others…*/])
// • Iterator.from([/*7 others…*/])
// • …

fc.iterator(fc.nat(9), { minLength: Number.POSITIVE_INFINITY });
// Note: Only never-ending iterators
// Examples of generated values: Iterator.from([/*…*/])…

fc.iterator(fc.nat(9), { noHistory: true });
// Note: By default, Iterators keep a history of generated values. Setting `noHistory` to `true` drops history to save memory. As such reported errors won't show any generated value
// Examples of generated values:
// • Iterator.from(/*0 emitted over 1*/)
// • Iterator.from(/*0 emitted over 10*/)
// • Iterator.from(/*0 emitted over 4*/)
// • Iterator.from(/*0 emitted over 2*/)
// • Iterator.from(/*0 emitted*/)
// • …
```
