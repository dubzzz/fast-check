# Iterable

Generate iterable values.

## iterator

Generate infinite `Iterator` of values generated by `arb`.

The generated instances implement the `Iterator` protocol and come with all the native iterator helpers such as `take`, `map` or `filter` to manipulate them.

**Signatures:**

- `fc.iterator(arb)`
- `fc.iterator(arb, {noHistory?})`

**with:**

- `arb` — _arbitrary instance responsible to generate values_
- `noHistory?` — default: `false` — Omit generated values from the string representation. Recommended for very large tests due to the history's unbounded memory use.

**Usages:**

```js
fc.iterator(fc.nat(9));
// Examples of generated values: Iterator.from([/*…*/])…

fc.iterator(fc.nat(9), { noHistory: true });
// Examples of generated values: Iterator.from(/*0 emitted*/)…
```

Available since 1.8.0.
